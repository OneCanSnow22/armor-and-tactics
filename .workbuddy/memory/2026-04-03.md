# 2026-04-03 工作日志

## 调查：map_manager.gd 中动画不切换的问题

- 项目：装甲与战术（Godot 4 棋盘战棋游戏）
- 问题：tween移动期间调用 `robot.walk()` 后角色仍播放 idle 动画
- 根本原因：`move_robot.gd` 的 `_physics_process` 每帧都在检测键盘输入 `ui_left/ui_right`，没有输入时强制调用 `animation.play("idle")`，覆盖了 `walk()` 的设置。
- 脚本关系：map_manager.gd（GameManager节点）控制移动逻辑；move_robot.gd（robot节点）控制动画和物理。
- 用户只需查明原因，不需要修改代码。

## 修复：能量消耗与获取动画时序（2026-04-05）

- 问题：consume_step_and_energy 和 enter_event 中的能量动画同时执行，视觉不协调
- 修复方案：
  - energy_bar.gd 的 consume_one 和 gain_energy 均新增 on_finished: Callable 回调参数
  - consume_step_and_energy 加入 on_finished 参数，动画播完才触发回调
  - animation_finished 将后续逻辑放入 consume_step_and_energy 的回调 lambda
  - enter_event id==2 时，gain_energy 完成后才调用 roll_dice_get_step()
  - 其他 enter_event 分支统一在事件处理后调用 roll_dice_get_step()
  - enter_event 原来的 step==0 改成 step<=0（更严格）
