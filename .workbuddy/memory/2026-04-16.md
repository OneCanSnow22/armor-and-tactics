# 2026-04-16

## 卡牌系统 context 动态求值
- `function._init()` 里不能用 `{}` 做字符串插值，GDScript 没有这个语法
- `context` 涉及运行时数据（如 `Profile.player.attack_mode.damage`）需改成 `get_context()` 方法动态求值，避免 `_init()` 时机过早导致 null

## match pattern 不能用运行时表达式
- `match` 的分支 pattern 必须是编译期常量
- 枚举值要通过类名访问（如 `Stack.Stack_mode.Melee`），不能通过实例（如 `stackArray[0].Stack_mode.Melee`）
