# 2026-04-19 工作日志

## 鼠标事件穿透修复
- `fight_menu.gd`：背景 TextureRect 及其子节点全部设为 `MOUSE_FILTER_IGNORE`
- `card_manager.gd`：ScaleRoot 和 Column/TextureRect 设为 `MOUSE_FILTER_IGNORE`
- 根因：CanvasLayer 下 Control 节点默认 STOP 会拦截 Area2D 的鼠标事件

## Character 选中 bug 修复
- `_on_area_2d_mouse_exited` 里 `flag=true` 改为 `flag=false`
- `_process` 里选中前先重置所有兄弟 Character 的 `isAimed`

## 溅射炮击范围 bug 修复
- `places.find(aimedCharacter)` → `places.find(aimedCharacter.place)`，类型不匹配导致 find 返回 -1

## card_manager 引用修复
- `fight_menu.gd` 的 `card_manager` 变量一直是 null，在 `_ready()` 加了 `get_node("Card_manager") as Card_Manager`

## 平衡设计讨论
- 射击未命中代价方向：确定采用"未命中降低攻击力 debuff"方案，未命中不消耗牌但伤害衰减，命中后清除 debuff

## 角色移动系统设计
- `fight_menu.gd` 新增 `move_character`、`can_move_to`、`_do_move` 三个函数
- 碰墙反弹逻辑：先尝试原方向，不行自动反弹反方向，两边都挡则无法移动
- 移动时判断"任何其他角色"占据（不只是敌人），排除自身
- `get_enemy_at` 保留用于攻击范围等场景，移动判断用独立的 can_move_to 遍历

## 动画队列架构讨论
- 队列应放在 `Card_Manager`，理由：触发/控制入口都在 card_manager，`AnimationUnit` 是纯数据类不适合持有队列
- `Profile` 是 AutoLoad 不应放临时状态，动画队列随战斗场景生命周期
