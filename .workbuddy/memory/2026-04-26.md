# 2026-04-26 日志

## 炮击叠加伤害机制 + 多敌人炮击修复

### 改动内容
- **Profile.gd `Shelling` 类**：新增 `bonus_damage:int = 0`（等待期叠加伤害）和 `is_targeting:bool = false`（各敌人实例独立的锁定标志，替代全局 playerIsTarget）
- **Profile.gd `Sputtering_type_artillery._init`**：补上缺失的 `max_time=info`
- **fight_menu.gd `_player_causeDamage`**：炮击等待期内再次触发 Swipe_animation 时，累加 `mode.bonus_damage += mode.damage`；发射时用 `damage + bonus_damage` 作为总伤害，发射后 `bonus_damage=0` 重置
- **fight_menu.gd `_enemy_causeDamage`**：敌人炮击改用 `mode.is_targeting` 替代全局 `playerIsTarget`，多个炮击敌人互不干扰
- **fight_menu.gd `update_enemy_shelling_time`**：同上，改用 `mode.is_targeting` 判断倒计时

### 伤害叠加 bug 修复
- **根因**：`trigger_shelling_attacks` 通过 `causeDamage()` → `_player_causeDamage` 触发炮击发射时，会先经过 else 分支的 `bonus_damage += damage` 叠加逻辑，多加了一次
- **修复**：提取 `_player_shelling_fire(mode)` 独立函数专门负责发射和清零，`trigger_shelling_attacks` 和 `_player_causeDamage` 共用此函数，避免发射时误走叠加分支
- 玩家移动：重置 `current_time` + 清零 `bonus_damage`
- 敌人被迫移动：重置 `current_time` + `is_targeting=false`，不涉及 `bonus_damage`（敌人无叠加机制）

### 伤害预览文本（BBCode 浮动效果）
- 新增 `damage_text.gd` + `damage_text.tscn`（RichTextLabel），选中敌人时头顶显示预计伤害
- 使用 BBCode：红色小字"预计伤害" + 黄色大字伤害数值
- 动画：从上方弹入 → 持续上下缓慢浮动 → dismiss() 淡出移除
- `fight_menu.gd` 新增 `_damage_text_node` 变量、`show_damage_text()`、`_dismiss_damage_text()`
- 在 `enemy_is_locked`（锁定时显示）、`_on_character_died`（死亡时移除）中集成

### 三个战斗 Bug 修复
- **Bug 1 近战连续伤害**：`_player_causeDamage` 近战分支 for 循环条件缺失 `continue` 对 Player 的跳过，且直接遍历 CharacterArray 导致 erase 后跳元素；改用 `duplicate()` + 完整条件检查
- **Bug 2 死亡隐藏攻击范围**：`Character._on_dead_frame_changed` 里死亡时调用了 `EnemybecomeSafe()` 隐藏了一个近战范围格；已移除该逻辑，范围清除由 fight_menu 统一管理
- **Bug 3 远程判定不跟随**：新增 `show_enemy_hit_range_for_all()`，玩家每次移动后刷新当前锁定敌人的攻击范围；修正 `_can_shelling_hit_player` 中 `PlayerTurnisDangerous` → `PlayerisDangerous`（Position 实际字段名）

### 机制说明
- 玩家炮击等待阶段：每打出一张含 Swipe_animation 的卡，额外伤害 += 基础伤害（有几个攻击模组叠加几次）
- 炮击发射后伤害归零，不影响下次炮击
- 全局变量 `playerIsTarget` 保留但已不参与逻辑（可后续清理）
